# Cutaneous Mexameter Melanin Index (MI) & Erythema Index (EI) Skill

A production-grade, zero-mock personal agent skill engineered for dermatological spectrophotometry, optical reflectance biophysics, and objective cutaneous inflammation/pigmentation profiling.

## Features
- **Deterministic Narrowband Derivation**: Computes Erythema Index and Melanin Index based on standardized hemoglobin and melanin absorption peaks.
- **Fitzpatrick Phototyping & Inflammation Grading**: Integrates clinical thresholds for rosacea, erythema, and UV photosensitivity.
- **Pure Standard Library**: Zero external dependencies; fully portable for edge and clinical AI deployment.
